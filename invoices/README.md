# Генератор счетов на оплату (РК)

Шаблон `template.xlsx` + скрипт `generate_invoice.py` заполняют лист
"Счет на оплату" реквизитами поставщика, покупателя и позициями товара.

## Использование

1. Подготовить JSON с данными (см. `last_data_example.json`):

```json
{
  "supplier": {
    "name": "ИП \"REEZQ\"",
    "address": "...",
    "bin": "...",
    "bank": "...",
    "kbe": 19,
    "bik": "CASPKZKA",
    "iik": "KZ..."
  },
  "buyer": {
    "name": "ТОО \"...\"",
    "address": "...",
    "bin": "..."
  },
  "items": [
    {"name": "Товар", "qty": 100, "price": 500, "unit": "шт"}
  ],
  "contract": "Без договора",
  "vat_rate": 0
}
```

2. Запустить:

```
python3 generate_invoice.py data.json Счет.xlsx
```

Номер счёта берётся из `counter.json` автоматически (и увеличивается на 1
при каждом запуске), если не указан явно полем `invoice_number`.
Дата по умолчанию — сегодняшняя (`invoice_date` можно переопределить).

Максимум 8 позиций товара (строки 27–34 в шаблоне).
